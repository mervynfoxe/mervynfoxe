## Contributing patches

If you'd like to submit a patch for one of my projects, first off thanks in advance for your contribution!

I host "canonical" versions of all my project repos on [my own server](https://git.mervyn.online/fox?tab=repositories), which is publicly accessible but not open to user registration. I try to mirror most of my active work on other public hosts such as [GitHub](https://github.com/mervynfoxe) or [Codeberg](https://codeberg.org/mervynfoxe), so feel free to use those as sources for cloning/forking.

My preferred method of accepting patches is via email. If you don't see conflicting details in a given project's info, then this route is a safe bet, but do check the README just in case a specific project prefers PRs.

**You can send me patches directly at `patches@dev.mervyn.online`.** Please add the repo name to the patch prefix to help diffentiate (e.g. `git format-patch HEAD~1 --subject-prefix="PATCH <project-name>"` or `git config format.subjectPrefix "PATCH <project-name>"`), and provide a cover letter if your patch contains multiple commits or involves detailed changes. If you need help sending patches over email, check out [git-send-email.io](https://git-send-email.io/).

As a fallback: I do occasionally check my mirrored repos for PRs, if you're more comfortable submitting changes that way, but I may be slower to address those. But, **for sensitive or high security issues, please contact or email a patch to me directly.** If you're not comfortable sending email patches, just reach out and we'll work something out.
